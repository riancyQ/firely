# FIRELY - 财务独立目标管理应用

一款帮助用户实现财务独立、提前退休（FIRE）目标的家庭理财规划工具。

## 功能特性

### Dashboard 核心指标

- **资金总余额**：本月资金总余额
- **年度理财总收益**：本年理财总收益
- **月度结余**：本月与上月资金余额差额
- **年度结余**：本年与去年资金余额差额

### 健康状态监控

- **储蓄健康状态**：基于年度储蓄率（N/A灰色，≥50%绿色，>0%<50%黄色，≤0%红色）
- **理财健康状态**：基于年化利率（N/A灰色，≥3.5%绿色，>0%<3.5%黄色，≤0%红色）

### FIRE 目标规划

- **FIRE 目标金额** = 年支出 / 安全提取率
- **距离 FIRE 所需金额**：目标与当前资产差额
- **FIRE 所需时间**：基于年储蓄和年化利率计算

### 收入记录管理

- 支持添加、编辑、删除收入记录
- 按月分组展示，显示月度资金总余额和理财总收益
- 自动计算月收益率

### 资金分布

- 饼状图展示各资金账户占比
- 按金额排序，大占比账户聚集显示
- 虚线连接标签，清晰展示百分比

### 资金余额和理财收益趋势

- 展示资金余额变化趋势
- 展示理财收益变化趋势
- 展示月度和年度变化趋势

### 数据导入导出

- **数据导出**：将所有数据（交易记录、资金账户、用户信息）导出为 JSON 文件
- **数据导入**：从 JSON 文件恢复数据，支持跨终端数据迁移
- **版本兼容性**：新版本可导入旧版本数据，旧版本无法导入新版本数据
- **安全提示**：导入前会覆盖现有数据，需确认操作

## 计算公式

### 1. 年化收益率

**计算公式**：

```
年化收益率 = (1+r₂) × (1+r₃) × ... × (1+rₙ)^(12/(n-1)) - 1  （2-11个月）
年化收益率 = (1+r₂) × (1+r₃) × ... × (1+r₁₂) - 1         （12个月及以上）
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| n | 月份数量 |
| n-1 | 收益率数量（第2个月开始才有收益率） |
| rᵢ | 第i个月的收益率 = 本月理财收益 / 上月资金余额 |
| 12/(n-1) | 将观测期收益率年化的指数 |

**数据量处理规则**：

| 数据量 | 计算方式 | 返回值 |
|--------|---------|--------|
| 0-1个月 | 数据不足，无法计算 | N/A |
| 2-11个月 | 几何平均年化 | `product^(12/(n-1)) - 1` |
| 12个月及以上 | 最近12个月实际收益 | `product - 1` |

---

### 2. 年度储蓄率

**计算公式**：

```
月度储蓄 = 本月资金余额变化 - 本月理财收益
年储蓄 = (月度储蓄之和 / (月份数-1)) × 12          （2-11个月）
年储蓄 = 最近12个月月度储蓄之和                     （12个月及以上）
年度储蓄率 = 年储蓄 / (年储蓄 + 用户年支出) × 100%
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| 资金余额变化 | 本月末资金余额 - 上月末资金余额 |
| 理财收益 | 投资产生的被动收益，不计入储蓄 |
| 用户年支出 | 用户在欢迎窗口输入的年支出 |

**数据量处理规则**：

| 数据量 | 年储蓄来源 | 储蓄率返回值 |
|--------|-----------|------------|
| 0-1个月 | N/A | N/A |
| 2-11个月 | 平均月储蓄 × 12 | 计算值 |
| 12个月及以上 | 最近12个月真实储蓄之和 | 计算值 |

---

### 3. FIRE 所需时间

**计算公式**：

```
K = ln((F × r + S) / (A × r + S)) / ln(1 + r)
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| A | 当前资产（从交易记录获取） |
| S | 年储蓄（根据数据量计算） |
| r | 年化收益率（根据数据量计算） |
| F | FIRE目标金额 = 年支出 / 安全提取率（默认3.5%） |

**数据量处理规则**：

| 数据量 | 年储蓄来源 | 年化收益率来源 |
|--------|-----------|---------------|
| 0-1个月 | 用户输入：年收入 - 年支出 | 风险偏好默认值（保守2.5%、稳健3.5%、激进4.5%） |
| 2-11个月 | 实际数据：平均月储蓄 × 12 | 实际数据：几何平均年化（≥3个月） |
| 12个月及以上 | 实际数据：最近12个月真实储蓄之和 | 实际数据：最近12个月收益率 |

---

### 4. 健康状态判断

**储蓄健康状态**：

| 条件 | 状态 | 颜色 | 显示文本 |
|------|------|------|---------|
| 数据不足（0-1个月） | ❓ 未知 | 灰色 #6b7280 | 数据不足，无法计算储蓄率 |
| 储蓄率 ≥ 50% | ✅ 优秀 | 绿色 #22c55e | 储蓄率非常健康！继续保持 |
| 0% < 储蓄率 < 50% | ⚠️ 注意 | 黄色 #eab308 | 财务状况有待提高！储蓄率较低 |
| 储蓄率 ≤ 0% | ❌ 危险 | 红色 #ef4444 | 储蓄率为负或零，需要调整支出习惯 |

**理财收益健康状态**：

| 条件 | 状态 | 颜色 | 显示文本 |
|------|------|------|---------|
| 数据不足（0-1个月） | ❓ 未知 | 灰色 #6b7280 | 数据不足，无法计算年化利率 |
| 年化利率 ≥ 3.5% | ✅ 优秀 | 绿色 #22c55e | 理财收益表现优秀！继续保持 |
| 0% < 年化利率 < 3.5% | ⚠️ 注意 | 黄色 #eab308 | 理财收益有待提高！可以考虑优化配置 |
| 年化利率 ≤ 0% | ❌ 危险 | 红色 #ef4444 | 理财收益为负或零，需要调整投资策略 |

## 技术栈

- **前端**：HTML, CSS, JavaScript
- **数据存储**：localStorage（浏览器本地存储）
- **静态服务器**：http-server
- **运行环境**：现代浏览器（Chrome、Firefox、Safari、Edge）

### 架构说明

采用三层架构设计：

| 层级        | 文件                     | 职责                   |
| --------- | ---------------------- | -------------------- |
| **视图层**   | index.html             | UI渲染、事件处理、页面交互       |
| **业务逻辑层** | frontendService.js     | 财务计算、报表生成、数据汇总       |
| **数据存储层** | localStorageService.js | localStorage操作、数据持久化 |

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

```bash
npm run dev
```

### 3. 访问应用

打开浏览器访问 <http://localhost:3000>

### 4. 首次使用

首次打开会弹出欢迎窗口，请填写：

- 目前家庭年收入（万元）**必填**
- 目前家庭年支出（万元）**必填**
- 您的家庭理财情况**必填**
