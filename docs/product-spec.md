# FIRELY - 财务独立目标管理应用 - 产品规格文档

## 产品定位：

一款帮助用户实现财务独立、提前退休（FIRE）目标的家庭理财规划工具。核心理念基于4%法则：如果资产的增值部分（4%的年化收益）大于年支出，理论上这笔钱永远不会花不完。实现FIRE需要关注支出、储蓄率和理财收益。用户通过月度快照式记录净资产和理财收益变化，获得FIRE目标进展和健康度，并持续做优化。

## 功能特性

### 欢迎界面

- 初次使用展示欢迎界面，引导用户输入以下信息：
  - **年收入**
  - **年支出**
  - **风险偏好**（决定预期年化收益率）：
    - 保守型：2.5%
    - 平衡型：3.5%
    - 进取型：4.5%
- 根据用户输入自动计算 FIRE 目标金额（详见计算公式第3节）

### 用户信息管理

- 支持用户根据年支出的实际情况随时更新
- 支持用户根据理财收益的实际情况随时更新

### 资金池管理

- 支持用户添加、编辑、删除资金池
- 每个资金池可设置账户名称，是否用于还款
- 资金池列表关联资金池，用户在添加记录时在资金池列表中选择

### Dashboard 核心指标

- **资金总余额**：本月资金总余额
- **年度理财总收益**：本年理财总收益
- **月度结余**：本月与上月资金余额差额
- **年度结余**：本年与去年资金余额差额

**边界**：
- 无数据时，所有指标显示 "¥ 0.00 万"
- 月度结余无上月数据时显示 "N/A"
- 年度结余无去年数据时显示 "N/A"
- 数据更新后自动刷新，无需手动刷新页面

### 健康状态监控

- **储蓄健康状态**：基于年度储蓄率，按以下规则展示

| 储蓄率 | 状态 | 颜色 | 显示文本 |
|--------|------|------|---------|
| 数据不足（0-1月） | ❓ 未知 | 灰色 #6b7280 | 数据不足，无法计算储蓄率 |
| ≥ 50% | ✅ 优秀 | 绿色 #22c55e | 储蓄率非常健康！继续保持 |
| 0% ~ 50% | ⚠️ 注意 | 黄色 #eab308 | 财务状况有待提高！储蓄率较低 |
| ≤ 0% | ❌ 危险 | 红色 #ef4444 | 储蓄率为负或零，需要调整支出习惯 |

- **理财健康状态**：基于年化利率，按以下规则展示

| 年化利率 | 状态 | 颜色 | 显示文本 |
|---------|------|------|---------|
| 数据不足（0-1月） | ❓ 未知 | 灰色 #6b7280 | 数据不足，无法计算年化利率 |
| ≥ 3.5% | ✅ 优秀 | 绿色 #22c55e | 理财收益表现优秀！继续保持 |
| 0% ~ 3.5% | ⚠️ 注意 | 黄色 #eab308 | 理财收益有待提高！可以考虑优化配置 |
| ≤ 0% | ❌ 危险 | 红色 #ef4444 | 理财收益为负或零，需要调整投资策略 |

**边界**：
- 数据为 0-1 个月时，储蓄率/年化利率显示 "N/A"，状态显示"数据不足"（灰色）
- 储蓄率恰好 0% 时，判定为"危险"
- 储蓄率恰好 50% 时，判定为"优秀"
- 年化利率恰好 0% 时，判定为"危险"
- 年化利率恰好 3.5% 时，判定为"优秀"

### FIRE 目标规划

- **FIRE 目标金额** = 年支出 / 理财收益率
- **距离 FIRE 所需金额**：目标与当前资产差额
- **FIRE 所需时间**：基于年储蓄和年化利率计算
- **FIRE 进度**：当前资产与目标资产的百分比

**边界**：
- 0 个月数据时，FIRE 进度显示 "0%"，所需时间使用默认值计算
- 当前资产 ≥ FIRE 目标金额时，进度显示 "100%"，所需时间显示 "已实现"
- 计算异常时，显示 "N/A" 而非崩溃
- 进度超过 100% 时封顶显示 "100%"
- **年化收益率 r < 0 时**：不计算具体年限，显示红色警告文案「⚠ 当前亏损中，建议优化投资组合」

### 收入记录管理

- 支持添加、编辑、删除收入记录
- 添加一条记录时，可输入资金存放地、资金余额、理财收益、备注和时间
- **资金余额和理财收益以「元」为单位输入**（如 42301.00），展示时自动转换为「万元」（如 ¥ 4.23 万）
- 按月分组展示，显示月度资金总余额和理财总收益
- 月分组下每个资金池分别展示资金余额和理财收益金额

**交互与边界**：
- 添加记录时，日期只能选择当天及之前的日期（不允许未来日期）
- 理财收益可输入负数，资金余额不可输入负数
- 保存时自动刷新 Dashboard、健康状态、图表等所有关联模块
- 删除记录时，弹出确认提示"是否确认删除？"，用户确认后才执行
- 编辑记录时，允许修改所有字段
- 无记录时，显示友好提示"暂无记录，点击添加开始记录"

### 资金分布

- 展示最近一个月的资金余额在资金池的分布
- 饼状图展示各资金账户占比
- 按金额排序，大占比账户聚集显示
- 虚线连接标签，清晰展示百分比
- 资金明细表中，按照资金账户占比从大到小排列，最后汇总资金总余额

**交互**：
- 点击饼图某一色块时，进入筛选模式：其他色块变为半透明（opacity: 0.4），只显示选中资金池的明细数据
- 再次点击同一色块或点击"显示全部"按钮，取消筛选恢复正常显示
- 占比 < 5% 的小区域，使用虚线引导线 + 百分比标签展示（避免重叠）

### 资金余额和理财收益趋势

- 展示资金余额变化趋势
- 展示理财收益变化趋势
- 展示月度和年度变化趋势

**理财收益趋势图负数显示规则**：
- 正数收益柱子显示为绿色（`#10b981`），位于零线上方
- 负数收益（亏损）柱子显示为红色（`#ef4444`），位于零线下方
- 存在负数时，显示虚线零线（`stroke-dasharray="4,4"`），零线与 Y 轴刻度 0 对齐
- 全为正数时，不显示零线和"亏损"图例
- Y 轴刻度步长采用"漂亮数字"算法（2×10ⁿ、5×10ⁿ、10×10ⁿ），确保 0 落在刻度线上
- 刻度步长 < 1 万时显示 1 位小数（如 0.5万），步长 ≥ 1 万时显示整数（如 1万）
- 图例：有负数时显示"正收益"（绿）和"亏损"（红），全为正数时仅显示"正收益"

**交互与边界**：
- 图表支持鼠标悬停查看详细数据
- 数据不足时，增长率标签显示 "N/A"
- 无数据时，显示友好提示"暂无趋势数据"

### 数据导入导出

- **数据导出**：将所有数据（交易记录、资金账户、用户信息）导出为 JSON 文件
- **数据导入**：从 JSON 文件恢复数据，支持跨终端数据迁移
- **版本兼容性**：新版本可导入旧版本数据，旧版本无法导入新版本数据
- **安全提示**：导入前会覆盖现有数据，需确认操作

**边界**：
- 导入文件格式错误时，提示"文件格式无效"
- 导入版本高于当前版本时，提示"文件版本过高，请升级应用后再导入"
- 导入版本低于或等于当前版本时，正常导入
- 导入前必须显示"此操作将覆盖现有数据，是否继续？"确认提示
- 导出文件名格式：`firely_export_YYYY-MM-DD.json`
- 导出时间戳为 ISO 格式

## 数字格式规则

### 金额类

| 维度 | 规则 | 说明 |
|------|------|------|
| **存储单位** | 元（整数） | 所有金额以最小单位存储，避免浮点精度问题 |
| **显示单位** | 万元 | 符合用户阅读习惯 |

| **负数前缀** | `-` | 余额、结余为负数时显示 |

### 输入规则

| 字段 | HTML type | step | min | 负数 | 单位 | 说明 |
|------|-----------|------|-----|------|------|------|
| 年收入 | `number` | 0.01 | 0 | ❌ | 万元 | 欢迎界面/编辑信息 |
| 年支出 | `number` | 0.01 | 0 | ❌ | 万元 | 欢迎界面/编辑信息 |

## 计算公式

### 1. 年化收益率

**计算公式**：

```
年化收益率 = (1+r₂) × (1+r₃) × ... × (1+rₙ)^(12/(n-1)) - 1  （2-11个月）
年化收益率 = (1+r₂) × (1+r₃) × ... × (1+r₁₂) - 1         （12个月及以上）
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| n | 月份数量 |
| n-1 | 收益率数量（第2个月开始才有收益率） |
| rᵢ | 第i个月的收益率 = 本月理财收益 / 上月资金余额 |
| 12/(n-1) | 将观测期收益率年化的指数 |

**数据量处理规则**：

| 数据量 | 计算方式 | 返回值 |
|--------|---------|--------|
| 0-1个月 | 数据不足，无法计算 | N/A |
| 2-11个月 | 几何平均年化 | `product^(12/(n-1)) - 1` |
| 12个月及以上 | 最近12个月实际收益 | `product - 1` |

---

### 2. 年度储蓄率

**计算公式**：

```
月度储蓄 = 本月资金余额变化 - 本月理财收益
年储蓄 = (月度储蓄之和 / (月份数-1)) × 12          （2-11个月）
年储蓄 = 最近12个月月度储蓄之和                     （12个月及以上）
年度储蓄率 = 年储蓄 / (年储蓄 + 用户年支出) × 100%
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| 资金余额变化 | 本月末资金余额 - 上月末资金余额 |
| 理财收益 | 投资产生的被动收益，不计入储蓄 |
| 用户年支出 | 用户在欢迎窗口输入的年支出 |

**数据量处理规则**：

| 数据量 | 年储蓄来源 | 储蓄率返回值 |
|--------|-----------|------------|
| 0-1个月 | N/A | N/A |
| 2-11个月 | 平均月储蓄 × 12 | 计算值 |
| 12个月及以上 | 最近12个月真实储蓄之和 | 计算值 |

---

### 3. FIRE 所需时间

**计算公式**：

```
K = ln((F × r + S) / (A × r + S)) / ln(1 + r)
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| A | 当前资产（从交易记录获取） |
| S | 年储蓄（根据数据量计算） |
| r | 年化收益率（根据数据量计算） |
| F | FIRE目标金额 = 年支出 / 安全提取率（默认3.5%） |

**数据量处理规则**：

| 数据量 | 年储蓄来源 | 年化收益率来源 |
|--------|-----------|---------------|
| 0-1个月 | 用户输入：年收入 - 年支出 | 风险偏好默认值（保守2.5%、稳健3.5%、激进4.5%） |
| 2-11个月 | 实际数据：平均月储蓄 × 12 | 实际数据：几何平均年化（≥3个月） |
| 12个月及以上 | 实际数据：最近12个月真实储蓄之和 | 实际数据：最近12个月收益率 |
