# FIRELY 财务独立目标管理应用开发技能

## 项目概述

一款帮助用户实现财务独立、提前退休（FIRE）目标的家庭理财规划工具。

## 技术栈

- **前端**：HTML, CSS, JavaScript
- **数据存储**：localStorage（浏览器本地存储）
- **静态服务器**：http-server
- **测试框架**：Jest + jsdom
- **运行环境**：现代浏览器（Chrome、Firefox、Safari、Edge）

## 核心功能模块

### 1. Dashboard 核心指标
| 卡片 | 数据来源 | 计算方式 |
|------|---------|---------|
| 资金总余额 | localStorage | 本月资金余额（最新月份） |
| 年度理财总收益 | localStorage | 本年所有月份理财收益之和 |
| 月度结余 | localStorage | 本月余额 - 上月余额 |
| 年度结余 | localStorage | 本年余额 - 去年余额 |

### 2. 健康状态监控
| 状态卡片 | 指标 | 阈值 |
|---------|------|------|
| 储蓄健康状态 | 储蓄率 | ≥50%绿色, >0%<50%黄色, ≤0%红色 |
| 理财健康状态 | 年化利率 | ≥3.5%绿色, >0%<3.5%黄色, ≤0%红色 |

### 3. FIRE 目标规划
- **FIRE目标** = 年支出 / 安全提取率
- **距离金额** = FIRE目标 - 当前资产
- **所需时间** = ln((F×r+S)/(A×r+S)) / ln(1+r)

### 4. 资金分布
- 数据来源：localStorage（交易记录）
- 只显示最近一个月的账户数据
- 按金额降序排列，大占比聚集显示

### 5. 收入记录管理
- CRUD操作：添加、编辑、删除收入记录
- 按月分组，每组显示资金总余额和理财总收益
- 月收益率 = 本月理财收益 / 上月资金余额

### 6. 数据导入导出
- **导出**：将所有数据（交易记录、资金账户、用户信息）导出为 JSON 文件
- **导入**：从 JSON 文件恢复数据，支持跨终端数据迁移
- **版本兼容性**：新版本可导入旧版本数据

## 计算公式

### 年化利率
```
年化收益率 = (1+r₂) × (1+r₃) × ... × (1+rₙ)^(12/(n-1)) - 1
```
- n = 月份数量
- n-1 = 收益率数量（第2个月开始计算）
- 0-1个月数据：N/A
- 2-11个月：复合增长率
- 12个月及以上：真实年化

### 储蓄率
```
每月储蓄 = 本月余额变化 - 本月理财收益
年度储蓄率 = 年储蓄 / (年储蓄 + 年支出) × 100%
```
- 0-1个月：N/A
- 2-11个月：月均 × 12
- 12个月+：过去12个月真实储蓄

### FIRE所需时间
```
K = ln((F×r+S)/(A×r+S)) / ln(1+r)
```
- A=当前资产, S=年储蓄, r=年收益率, F=FIRE目标

## 用户数据存储

用户信息存储在浏览器 `localStorage` 中：
```javascript
{
  annualIncome: number,    // 年收入（元）
  annualExpense: number,  // 年支出（元）
  riskProfile: string     // 理财情况
}
```

## 数据导入导出

### 导出格式
```json
{
  "appVersion": "2.0",
  "exportTime": "2026-06-30T10:00:00.000Z",
  "data": {
    "transactions": [...],
    "depositAccounts": [...],
    "userInfo": {...},
    "nextIds": {...}
  }
}
```

### 导入规则
1. 版本检查：导入文件版本必须 ≤ 当前应用版本（2.0）
2. 数据覆盖：导入会清除现有数据并替换为导入数据
3. 格式验证：必须包含 `data` 字段，否则导入失败

## 常用命令

```bash
# 安装依赖
npm install

# 开发模式启动（http-server）
npm run dev

# 构建（复制 public 到 build）
npm run build

# 运行所有测试
npm test

# 仅运行P0核心测试
npm run test:p0

# 仅运行导入导出测试
npm run test:io

# 监听模式运行测试
npm run test:watch
```
